Experiment 1 — RGB LED Pins (Common Cathode)
Write an Arduino program to control an RGB LED with a common cathode configuration. The program should set the LED to display red, green, and blue colours sequentially with a delay of 1 second between each colour.
Aim: Interface LED (Common Cathode)
Hardware: Universal Board, Arduino Board, RGB LED (CC), 5V Adaptor, Power jack, USB Cable, Jumper wires
Hardware Procedure
Connect the red anode to digital pin 9.
Connect the green anode to digital pin 10.
Connect the blue anode to digital pin 11.
Connect the common cathode to the GND pin on Arduino.
Connect your Arduino board to your computer using the USB cable.
Software Procedure
In the Arduino IDE, choose correct board and COM port from Tools menu.
Write the program as per circuit connections. Save the sketch with .ino extension.
Click on Verify for compiling the code.
Click on Upload to upload the code to the configured board.
Arduino Program
Copy
#include <Arduino.h>

/* RGB LED pins (Common Cathode) */
#define Red_Pin 9
#define Green_Pin 10
#define Blue_Pin 11

/* Delay (in milliseconds) */
#define COLOR_CHANGE_DELAY 1000

void setup() {
  /* Initialize the RGB LED pins as outputs */
  pinMode(Red_Pin, OUTPUT);
  pinMode(Green_Pin, OUTPUT);
  pinMode(Blue_Pin, OUTPUT);
}

void loop() {
  /* Turn on Red, turn off Green and Blue */
  digitalWrite(Red_Pin, HIGH);
  digitalWrite(Green_Pin, LOW);
  digitalWrite(Blue_Pin, LOW);
  delay(COLOR_CHANGE_DELAY);

  /* Turn off Red, turn on Green, turn off Blue */
  digitalWrite(Red_Pin, LOW);
  digitalWrite(Green_Pin, HIGH);
  digitalWrite(Blue_Pin, LOW);
  delay(COLOR_CHANGE_DELAY);

  /* Turn off Red, turn off Green, turn on Blue */
  digitalWrite(Red_Pin, LOW);
  digitalWrite(Green_Pin, LOW);
  digitalWrite(Blue_Pin, HIGH);
  delay(COLOR_CHANGE_DELAY);

  /* Turn ON Red, Green, Blue (White) */
  digitalWrite(Red_Pin, HIGH);
  digitalWrite(Green_Pin, HIGH);
  digitalWrite(Blue_Pin, HIGH);
  delay(COLOR_CHANGE_DELAY);
}
Result: The code lights up the RGB LED with the colours red, green, blue, and white, pausing for a second on each colour.

Hardware Procedure
Connect the red cathode to digital pin 9.
Connect the green cathode to digital pin 10.
Connect the blue cathode to digital pin 11.
Connect the common anode to the 5V pin on Arduino.

Write the program as per circuit connections. Save the sketch with .ino extension.

Arduino Program
Copy
#include <Arduino.h>

/* RGB LED pins (Common Anode) */
#define Red_Pin 9
#define Green_Pin 10
#define Blue_Pin 11

/* Delay (in milliseconds) */
#define COLOR_CHANGE_DELAY 1000

void setup() {
  pinMode(Red_Pin, OUTPUT);
  pinMode(Green_Pin, OUTPUT);
  pinMode(Blue_Pin, OUTPUT);
}

void loop() {
  /* Pattern 1: Red */
  digitalWrite(Red_Pin, LOW);    // Turn on Red (Common Anode: LOW = ON)
  digitalWrite(Green_Pin, HIGH);
  digitalWrite(Blue_Pin, HIGH);
  delay(COLOR_CHANGE_DELAY);

  /* Pattern 2: Green */
  digitalWrite(Red_Pin, HIGH);
  digitalWrite(Green_Pin, LOW);  // Turn on Green
  digitalWrite(Blue_Pin, HIGH);
  delay(COLOR_CHANGE_DELAY);

  /* Pattern 3: Blue */
  digitalWrite(Red_Pin, HIGH);
  digitalWrite(Green_Pin, HIGH);
  digitalWrite(Blue_Pin, LOW);   // Turn on Blue
  delay(COLOR_CHANGE_DELAY);

  /* Pattern 4: White (Red + Green + Blue) */
  digitalWrite(Red_Pin, LOW);
  digitalWrite(Green_Pin, LOW);
  digitalWrite(Blue_Pin, LOW);
  delay(COLOR_CHANGE_DELAY);
}
Result: The code lights up the RGB LED with the colours red, green, blue, and white, pausing for a second on each colour.
Experiment 3 — Buzzer
Write an Arduino program to control a buzzer connected to a digital pin. The program should make the buzzer sound a beep for 500 milliseconds, followed by a 500-millisecond pause, and repeat this pattern continuously.
Aim: Interface buzzer with Arduino to buzz for a period of time
Hardware: Universal Board, Arduino Board, Buzzer, 5V Adaptor, Power jack, USB Cable, Jumper wires
Hardware Procedure
Connect the Buzzer pin to digital pin 8.
Connect your Arduino board to your computer using the USB cable.
Software Procedure
In the Arduino IDE, choose correct board and COM port from Tools menu.
Write the program as per circuit connections. Save the sketch with .ino extension.
Click on Verify for compiling the code.
Click on Upload to upload the code to the configured board.
Arduino Program
Copy
#include <Arduino.h>

const int buzzerPin = 8;
const int beepDuration = 200;
const int numBeeps = 5;

void beep(void);

void setup() {
  pinMode(buzzerPin, OUTPUT);
}

void loop() {
  for (int i = 0; i < numBeeps; i++) {
    beep();
    delay(500);
  }
  delay(2000);
}

void beep(void) {
  digitalWrite(buzzerPin, HIGH);
  delay(beepDuration);
  digitalWrite(buzzerPin, LOW);
  delay(100);
}
Result: The buzzer beeps 5 times with a 500ms gap between beeps, then pauses for 2 seconds before repeating.
Experiment 4 — Interfacing Push Button (Pull-up)
Write an Arduino program to control LED using a push button.
Aim: Control LED using a push button
Hardware: Arduino Board, Push Button, LED, Resistors, Jumper wires
Arduino Program
Copy
#include <Arduino.h>

#define buttonPin 2
#define ledPin 13

void setup() {
  pinMode(buttonPin, INPUT_PULLUP);  // Enable internal pull-up
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int buttonState = digitalRead(buttonPin);

  if (buttonState == LOW) {  // Button pressed (pulls to GND)
    digitalWrite(ledPin, HIGH);
    Serial.println("Button Pressed");
  } else {
    digitalWrite(ledPin, LOW);
    Serial.println("Button Released");
  }
  delay(1000);
}
Result: Pressing the button turns the LED on and prints "Button Pressed"; releasing turns it off and prints "Button Released".
Experiment 5 — Relay Control
Write an Arduino program to control a relay using Arduino with an input given through a push button.
Aim: Control Relay using Arduino
Hardware: Arduino Board, Relay Module, Push Button, Jumper wires
Arduino Program
Copy
#include <Arduino.h>

// Define the relay control pin
const int relayPin = 13;

void setup() {
  // Initialize the relay control pin as an output
  pinMode(relayPin, OUTPUT);

  // Initialize serial communication
  Serial.begin(9600);
  Serial.println("Relay Control for 230V Appliance:");

  // Turn off the relay initially for safety
  digitalWrite(relayPin, LOW);
}

void loop() {
  // Prompt the user to control the appliance
  Serial.println("Enter '1' to turn ON, '0' to turn OFF:");

  while (Serial.available() <= 0);
  char command = Serial.read();

  if (command == '1') {
    Serial.println("Turning ON the Relay...");
    digitalWrite(relayPin, HIGH);  // Turn ON the relay
  } else if (command == '0') {
    Serial.println("Turning OFF the Relay...");
    digitalWrite(relayPin, LOW);   // Turn OFF the relay
  } else {
    Serial.println("Enter '1' to turn ON, '0' to turn OFF.");
  }

  // Wait for a moment
  delay(2000);
}
Result: Send '1' via Serial Monitor to turn relay ON, '0' to turn it OFF. Status messages appear on the Serial Monitor.
Experiment 6 — Sliding Switch
Write a program to read the data from the Sliding switch and display the information on serial monitor using Arduino and control LED.
Aim: Read sliding switch state and display on Serial Monitor
Hardware: Arduino Board, Sliding Switch, LED, Jumper wires
Arduino Program
Copy
#include <Arduino.h>

// Define the slide switch pin
const int switchPin = 2;

void setup() {
  // Initialize the slide switch pin as an input with pull-up
  pinMode(switchPin, INPUT_PULLUP);

  // Initialize serial communication
  Serial.begin(9600);
  Serial.println("Slide Switch Status:");
}

void loop() {
  int switchState = digitalRead(switchPin);

  // Check if the slide switch is in the ON position
  if (switchState == LOW) {
    Serial.println("Switch ON");
  } else {
    Serial.println("Switch OFF");
  }

  delay(500);  // Small delay to avoid rapid toggling of status
}
Result: Serial Monitor displays "Switch ON" or "Switch OFF" based on the sliding switch position, updated every 500ms.
Experiment 7 — Potentiometer
Write an Arduino program to read the voltage from a Potentiometer connected to an analog pin. The program should print the voltage value to the Serial Monitor every second.
Aim: Read voltage from potentiometer
Hardware: Arduino Board, Potentiometer (10kΩ), Jumper wires
Hardware Procedure
Connect the two outer terminals of the potentiometer to 5V and GND.
Connect the middle terminal (wiper) to analog pin A1.
Connect your Arduino board to your computer using the USB cable.
Arduino Program
Copy
#include <Arduino.h>

const int POTENTIOMETER_PIN = A1;

void setup() {
  Serial.begin(9600);
}

void loop() {
  uint16_t sensorValue = analogRead(POTENTIOMETER_PIN);

  Serial.print("RAWDATA: ");
  Serial.print(sensorValue);

  float voltage = (sensorValue / 1023.0) * 5.0;
  Serial.print("  Voltage: ");
  Serial.print(voltage, 2);  // Print with 2 decimal places
  Serial.println(" V");

  delay(500);
}
Result: Serial Monitor displays raw ADC value (0-1023) and the corresponding voltage (0-5V), updating every 500ms.
Experiment 8 — Controlling LED Brightness using Potentiometer
Write an Arduino program to read the voltage from a Potentiometer connected to an analog pin. The program should print the voltage value to the Serial Monitor every second and control the brightness of LED.
Aim: Control LED brightness with potentiometer via PWM
Hardware: Arduino Board, Potentiometer, LED, 220Ω Resistor, Jumper wires
Arduino Program
Copy
#include <Arduino.h>

const int POTENTIOMETER_PIN = A1;
const int LED_PIN = 9;  // PWM pin

void setup() {
  Serial.begin(9600);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  uint16_t sensorValue = analogRead(POTENTIOMETER_PIN);

  Serial.print("RAWDATA: ");
  Serial.print(sensorValue);

  float voltage = (sensorValue / 1023.0) * 5.0;
  Serial.print("  Voltage: ");
  Serial.print(voltage, 2);
  Serial.println(" V");

  int brightness = sensorValue / 4;  // Map 0-1023 to 0-255
  analogWrite(LED_PIN, brightness);

  delay(1000);
}
Result: Turning the potentiometer changes the LED brightness. Serial Monitor displays the raw value and voltage simultaneously.

Experiment 10 — Ultrasonic Sensor
Write an Arduino program to measure the distance using an ultrasonic sensor. The program should send out an ultrasonic pulse, measure the time it takes for the echo to return, and then calculate and display the distance in centimetres on the Serial Monitor.
Aim: Measure distance using HC-SR04 Ultrasonic Sensor
Hardware: Arduino Board, HC-SR04 Ultrasonic Sensor, Jumper wires
Hardware Procedure
Connect VCC to 5V, GND to GND.
Connect Trig to digital pin 8.
Connect Echo to digital pin 9.
Connect your Arduino board to your computer using the USB cable.
Arduino Program
Copy
#include <Arduino.h>

const int TRIGGER_PIN = 8;
const int ECHO_PIN = 9;
const float SPEED_OF_SOUND = 343.0;

void setup() {
  Serial.begin(9600);
  pinMode(TRIGGER_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
}

void loop() {
  digitalWrite(TRIGGER_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIGGER_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIGGER_PIN, LOW);

  long duration = pulseIn(ECHO_PIN, HIGH);
  float distance = (duration * 0.5 * SPEED_OF_SOUND) / 10000.0;

  Serial.print("Distance: ");
  Serial.print(distance, 2);  // Print with 2 decimal places
  Serial.println(" cm");

  delay(1000);
}
Result: Serial Monitor displays the measured distance in centimetres (e.g., "Distance: 15.32 cm"), updating every second.
Experiment 11 — Temperature Measurement using LM35 Sensor
To interface LM35 temperature sensor with Arduino UNO and measure the ambient temperature by converting the analog output voltage of the sensor into Celsius scale and display it on the Serial Monitor.
Aim: Interface LM35 temperature sensor with Arduino UNO
Hardware: Arduino UNO, LM35 Sensor, Breadboard, Jumper wires, USB cable
Hardware Procedure
Place the LM35 sensor on the breadboard.
Connect the VCC pin of LM35 to 5V pin of Arduino UNO.
Connect the GND pin of LM35 to GND pin of Arduino UNO.
Connect the OUT (signal) pin of LM35 to Analog pin A0 of Arduino UNO.
Connect the Arduino UNO to the computer using the USB cable.
Ensure all connections are firm and there are no short circuits.
Software Procedure
Open Arduino IDE on your computer.
Create a new sketch and paste the following code.
Select the correct board (Tools → Board → Arduino AVR Boards → Arduino Uno) and the correct COM port (Tools → Port).
Click Verify to compile the sketch, then Upload to transfer the program to the Arduino board.
After successful upload, open the Serial Monitor (Tools → Serial Monitor) and set the baud rate to 9600.
The program continuously reads the analog value from pin A0, converts it to voltage and then to temperature, and prints the result every 1 second.
Arduino Program
Copy
#include <Arduino.h>

int sensorPin = A0;
float temperature;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int reading = analogRead(sensorPin);
  float voltage = reading * (5.0 / 1023.0);
  temperature = voltage * 100;  // LM35 gives 10mV per °C

  Serial.print("Temperature: ");
  Serial.print(temperature);
  Serial.println(" °C");

  delay(1000);
}
Result: The Serial Monitor continuously displays the current temperature in °C (e.g., "Temperature: 28.50 °C"). The value changes according to the ambient temperature around the LM35 sensor.

Experiment 13 — Touch Sensor Controlled Relay
To interface a touch sensor and relay module with Arduino UNO so that a touch on the sensor activates/deactivates the relay (simulating door/open-close control) and displays the status on the Serial Monitor.
Aim: Interface touch sensor and relay module with Arduino UNO
Hardware: Arduino UNO, Touch Sensor Module, Relay Module (5V), Breadboard, Jumper wires
Hardware Procedure
Connect Touch sensor: VCC → 5V, GND → GND, SIG (OUT) → Digital pin 7 of Arduino.
Connect Relay module: VCC → 5V, GND → GND, IN → Digital pin 2 of Arduino.
(If using load) Connect the appliance between Common and Normally Open (NO) terminals of the relay.
Power the Arduino via USB.
Software Procedure
Open Arduino IDE and paste the code.
Verify → Upload the sketch (board = Arduino Uno, correct COM port).
Open Serial Monitor at 9600 baud.
The code sets pin 7 as input and pin 2 as output. On every loop it reads the touch sensor; if HIGH (touched), it turns the relay ON and prints the detection message.
Arduino Program
Copy
const int SENSOR_PIN = 7;
const int RELAY = 2;

void setup() {
  Serial.begin(9600);
  pinMode(SENSOR_PIN, INPUT);
  pinMode(RELAY, OUTPUT);
}

void loop() {
  int state = digitalRead(SENSOR_PIN);
  digitalWrite(RELAY, state);

  if (state == 1) {
    Serial.println("Human is detected. Open the Door!!!");
  }
}
Result: When the touch sensor is touched, Relay clicks ON (LED on relay module lights up), and Serial Monitor prints "Human is detected. Open the Door!!!" repeatedly while the finger remains on the sensor. Releasing the touch turns the relay OFF.
Experiment 14 — Street Light Control using LDR
To interface an LDR (Light Dependent Resistor) sensor with Arduino UNO and automatically control an LED (simulating street light) based on ambient light intensity — turn ON in darkness and OFF in bright light — with status messages on the Serial Monitor.
Aim: Automatic street light control using LDR
Hardware: Arduino UNO, LDR Sensor Module, LED (or built-in pin 13), Resistor, Jumper wires
Hardware Procedure
Connect LDR module: VCC → 5V, GND → GND, DO (Digital Out) → Digital pin 3 of Arduino.
Connect LED: Anode (long leg) → Digital pin 13 via 220Ω resistor, Cathode → GND (or use on-board LED).
Power the board via USB.
Software Procedure
Open Arduino IDE and paste the code.
Verify, select board/port, and Upload.
Open Serial Monitor (9600 baud).
The program reads the digital output of the LDR module. Logic is inverted: LDR module outputs LOW in bright light → LED OFF; outputs HIGH in darkness → LED ON.
Arduino Program
Copy
#define LDR 3
#define LED 13

void setup() {
  pinMode(LDR, INPUT);
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  bool Sensor_Value = digitalRead(LDR);

  if (Sensor_Value == 0) {
    digitalWrite(LED, 0);
    Serial.println("Light is detected. It is Morning. Street lights are turned off");
  } else {
    digitalWrite(LED, 1);
    Serial.println("Dark... Street lights are Turned on");
  }
}
Result: In bright light, LED turns OFF and Serial prints "Light is detected... Street lights are turned off". In darkness, LED turns ON and Serial prints "Dark... Street lights are Turned on". The system automatically controls the LED based on ambient light.
Experiment 15 — Interfacing an RGB LED with Arduino UNO using PWM
To interface a Common Anode RGB LED with Arduino UNO and control its color mixing and brightness using Pulse Width Modulation (PWM) on digital pins. This allows smooth variation in color intensity rather than simple on/off states.
Aim: Control RGB LED color mixing and brightness using PWM
Hardware: Arduino UNO, RGB LED (Common Anode), 220Ω Resistors (x3), Breadboard, Jumper wires
Hardware Procedure
Connect the common anode of the RGB LED to the 5V pin on Arduino UNO.
Connect the red cathode to PWM digital pin 9 (via 220Ω resistor).
Connect the green cathode to PWM digital pin 10 (via 220Ω resistor).
Connect the blue cathode to PWM digital pin 11 (via 220Ω resistor).
Connect your Arduino UNO board to your computer using the USB cable.
Software Procedure
Open the Arduino IDE on your computer.
Create a new sketch and paste the following code.
Select the correct board (Tools → Board → Arduino AVR Boards → Arduino Uno) and the correct COM port (Tools → Port).
Click Verify to compile the sketch, then Upload to transfer the program to the Arduino board.
After successful upload, open the Serial Monitor (Tools → Serial Monitor) and set the baud rate to 9600.
Arduino Program
Copy
// Experiment 15: RGB LED Control with PWM

const int redPin = 9;    // PWM pin for Red
const int greenPin = 10; // PWM pin for Green
const int bluePin = 11;  // PWM pin for Blue

void setup() {
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
  Serial.begin(9600);
  Serial.println("RGB LED PWM Control Ready");
}

void setColor(int red, int green, int blue) {
  analogWrite(redPin, 255 - red);     // Invert because Common Anode
  analogWrite(greenPin, 255 - green);
  analogWrite(bluePin, 255 - blue);
}

void loop() {
  // Red
  setColor(255, 0, 0);
  Serial.println("Color: Red");
  delay(1000);

  // Green
  setColor(0, 255, 0);
  Serial.println("Color: Green");
  delay(1000);

  // Blue
  setColor(0, 0, 255);
  Serial.println("Color: Blue");
  delay(1000);

  // Yellow (Red + Green)
  setColor(255, 255, 0);
  Serial.println("Color: Yellow");
  delay(1000);

  // Cyan (Green + Blue)
  setColor(0, 255, 255);
  Serial.println("Color: Cyan");
  delay(1000);

  // Magenta (Red + Blue)
  setColor(255, 0, 255);
  Serial.println("Color: Magenta");
  delay(1000);

  // White (Full brightness)
  setColor(255, 255, 255);
  Serial.println("Color: White");
  delay(1000);

  // Fade demonstration (smooth transition from Blue to Red)
  for (int brightness = 0; brightness <= 255; brightness += 5) {
    setColor(brightness, 0, 255 - brightness);
    delay(20);
  }

  delay(500);
}
Result: The RGB LED cycles through primary colors (Red, Green, Blue), secondary colors (Yellow, Cyan, Magenta), and White. PWM control enables smooth brightness variation. The Serial Monitor prints the current color. In the fade section, the LED demonstrates smooth transitions from Blue to Red.
